```text
LinearLayout root
├── LinearLayout header
├── FrameLayout content
│   ├── paneAlarms
│   ├── paneWorldClock

│   ├── paneTimer
```

`FrameLayout` phù hợp ở đây vì các pane nằm chồng cùng vị trí. Java chỉ cho một pane `VISIBLE`, các pane còn lại là `GONE`.

# 2. World Clock layout

## Trong `activity_main.xml`

```xml
<NestedScrollView android:id="@+id/paneWorldClock">
    <LinearLayout android:id="@+id/worldClockList"/>
</NestedScrollView>
```

### `NestedScrollView`

Dùng để cuộn danh sách thành phố theo chiều dọc.

Nó chỉ được có một View con trực tiếp, nên bên trong là một `LinearLayout`.

### `LinearLayout`

`worldClockList` là nơi Java thêm lần lượt các `item_world_clock`.

Danh sách chỉ có 10 thành phố cố định nên dùng `LinearLayout`, không bắt buộc dùng RecyclerView.

## `item_world_clock.xml`

File: [item_world_clock.xml](C:/Users/24hph/AndroidStudioProjects/samsung_alarm/app/src/main/res/layout/item_world_clock.xml)

Các View:

| View | ID | Vai trò |
|---|---|---|
| `LinearLayout` | Root | Card của một thành phố |
| `LinearLayout` | Không có ID | Cột tên thành phố và quốc gia |
| `TextView` | `worldCityName` | Tên thành phố |
| `TextView` | `worldCityMeta` | Quốc gia và UTC offset |
| `LinearLayout` | Không có ID | Cột giờ và ngày |
| `TextView` | `worldCityTime` | Giờ hiện tại |
| `TextView` | `worldCityDate` | Thứ và ngày |

```text

    └── TextView ngày
```

`layout_weight=1` ở cột trái giúp đẩy cột giờ sang sát phải.

# 3. Quick Alarm layout

## Trong `activity_main.xml`

Pane Quick Alarm sử dụng:

| View | Công dụng |
|---|---|
| `NestedScrollView` | Cuộn toàn bộ màn Quick Alarm |
| `LinearLayout` | Xếp các thành phần theo chiều dọc |
| `TextView` | Tiêu đề, mô tả và tiêu đề danh sách |
| `MaterialButton` | Các nút 5, 10, 15, 30 phút và nút đặt |
| `TextInputLayout` | Bao ngoài ô nhập phút |
| `TextInputEditText` | Nhập số phút tùy chỉnh |
| `MaterialSwitch` | Bật giải toán |
| `RecyclerView` | Hiển thị toàn bộ Quick Alarm |
| `TextView` | Thông báo danh sách rỗng |

### Tại sao dùng `NestedScrollView`?

Vì màn Quick Alarm không chỉ có danh sách mà còn có nhiều nút và ô nhập ở phía trên. Người dùng cần cuộn toàn bộ nội dung.

### Tại sao vẫn dùng RecyclerView bên trong?

Vì số lượng Quick Alarm thay đổi động. Mỗi báo thức cần một item riêng, có nút xóa riêng.

RecyclerView được đặt:

```xml
android:nestedScrollingEnabled="false"
```

để `NestedScrollView` xử lý việc cuộn chính.

# 4. Timer layout

Timer nằm trực tiếp trong `activity_main.xml`.

Các View:

| View | ID | Vai trò |
|---|---|---|
| `LinearLayout` | `paneTimer` | Container chính |
| `TextView` | `timerDisplay` | Thời gian còn lại |
| `SeekBar` | `timerSeek` | Chọn nhanh 1–120 phút |
| `TextView` | Không có ID | Hướng dẫn phạm vi SeekBar |
| `TextInputLayout` | `timerMinutesLayout` | Khung nhập và hiện lỗi |
| `TextInputEditText` | `timerMinutesInput` | Nhập 1–10.080 phút |
| `LinearLayout` | Không có ID | Nhóm nút |
| `MaterialButton` | `timerReset` | Reset Timer |
| `MaterialButton` | `timerStart` | Start/Pause/Resume |

Cấu trúc:

```text
LinearLayout dọc
├── TextView timerDisplay
├── SeekBar timerSeek
├── TextView hướng dẫn
├── TextInputLayout
│   └── TextInputEditText
└── LinearLayout ngang
    ├── MaterialButton Reset
    └── MaterialButton Start
```

### Vì sao dùng `TextInputLayout`?

`TextInputLayout` cung cấp:

- Viền Material Design.
- Floating hint.
- Helper text.
- Hiển thị lỗi qua `setError()`.

`TextInputEditText` là ô nhập thực tế bên trong.

### Vì sao dùng `SeekBar`?

Nó giúp chọn nhanh khoảng thời gian thường dùng. Nhưng vì SeekBar chỉ tối đa 120 phút nên ô nhập tay hỗ trợ đến 10.080 phút.

# 5. Stopwatch layout

Stopwatch cũng nằm trong `activity_main.xml`.

Các View:

| View | ID | Vai trò |
|---|---|---|
| `LinearLayout` | `paneStopwatch` | Container chính |
| `TextView` | `stopwatchDisplay` | Thời gian đã chạy |
| `LinearLayout` | Không có ID | Nhóm ba nút |
| `MaterialButton` | `stopwatchReset` | Reset |
| `MaterialButton` | `stopwatchFlag` | Lưu mốc |
| `MaterialButton` | `stopwatchStart` | Start/Pause/Resume |
| `ScrollView` | Không có ID | Cuộn danh sách flag |
| `LinearLayout` | `stopwatchFlagList` | Chứa các item flag |

Cấu trúc:

```text
LinearLayout dọc
├── TextView stopwatchDisplay
├── LinearLayout ngang
│   ├── MaterialButton Reset
│   ├── MaterialButton Flag
│   └── MaterialButton Start
└── ScrollView
    └── LinearLayout stopwatchFlagList
```

Không dùng RecyclerView cho flag. Mỗi lần nhấn Flag, Java inflate một `item_stopwatch_flag` rồi thêm trực tiếp vào `LinearLayout`.

Cách này đơn giản với số lượng flag nhỏ. Nếu có hàng trăm hoặc hàng nghìn flag thì RecyclerView sẽ hiệu quả hơn.

# 7. Bottom navigation

Ở cuối `activity_main.xml`, navigation sử dụng một `LinearLayout` ngang chứa năm `MaterialButton`:

- `navAlarm`.
- `navWorldClock`.
- `navQuick`.
- `navTimer`.
- `navStopwatch`.

Mỗi nút có:

```xml
android:layout_width="0dp"
android:layout_weight="1"
```

Năm nút chia đều chiều rộng màn hình.

Icon đặt phía trên chữ bằng:

```xml
app:iconGravity="top"
```

Đây là navigation tự xây dựng bằng MaterialButton, không sử dụng `BottomNavigationView`.

# 8. Phân biệt các View dễ bị hỏi

| View | Khi nào dùng trong dự án |
|---|---|
| `View` | Lớp cơ sở của mọi thành phần giao diện |
| `TextView` | Chỉ hiển thị chữ/thời gian |
| `TextInputEditText` | Cho người dùng nhập dữ liệu |
| `TextInputLayout` | Bao ngoài EditText để có hint và error |
| `Button` | Nút cơ bản; Java khai báo kiểu cha cho MaterialButton |
| `MaterialButton` | Nút Material hiện đại |
| `ImageButton` | Nút chỉ có icon và nhận click |
| `ImageView` | Chỉ hiển thị icon, không dùng như nút |
| `MaterialSwitch` | Trạng thái bật/tắt |
| `SeekBar` | Chọn giá trị liên tục |
| `LinearLayout` | Sắp xếp View ngang hoặc dọc |
| `FrameLayout` | Chứa các pane chồng lên cùng vị trí |
| `ScrollView` | Cuộn một View con |
| `NestedScrollView` | Cuộn tốt hơn khi có View cuộn lồng nhau |
| `RecyclerView` | Danh sách động, tái sử dụng item |
| `FloatingActionButton` | Hành động chính: thêm báo thức |

Điểm quan trọng nhất để trình bày là:

- World Clock dùng `NestedScrollView + LinearLayout` vì chỉ có 10 thành phố cố định.
- Quick Alarm dùng `RecyclerView` vì danh sách thay đổi động và có thể có nhiều item.
- Stopwatch flag dùng `ScrollView + LinearLayout` vì triển khai đơn giản, số mốc dự kiến nhỏ.
- Các pane dùng `FrameLayout` để ẩn/hiện trên cùng một vùng nội dung.
- Timer dùng cả `SeekBar` và `TextInputEditText` để vừa chọn nhanh vừa nhập được thời gian dài.
